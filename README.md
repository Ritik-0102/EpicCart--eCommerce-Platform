# EpicCart

EpicCart is a modern, responsive full-stack e-commerce platform.

## Architecture
- **Frontend:** React.js (Vite)
- **Backend:** Node.js (Express.js)

## Setup Instructions

### Prerequisites
- Node.js installed on your machine.

### Running the Frontend
1. Navigate to the frontend directory: `cd frontend`
2. Install dependencies (if not already done): `npm install`
3. Start the development server: `npm run dev`

### Running the Backend
1. Navigate to the backend directory: `cd backend`
2. Install dependencies (if not already done): `npm install`
3. Start the server: `node server.js`

## Development Rules
This project follows strict beginner-friendly development rules, including clean architecture, separation of concerns (Frontend/Backend), and detailed documentation.
